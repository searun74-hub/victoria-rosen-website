# אתר ויקטוריה רוזן

אתר סטטי (HTML/CSS/JS בלבד, ללא שרת/build) לוויקטוריה רוזן, כותבת מילים ומלחינה.

## מבנה הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | דף הבית: Hero, אודות, טעימה משירים, מילים לדוגמה, שירותים, טופס קשר |
| `songs.html` | קטלוג מלא של כל השירים |
| `song.html` | תבנית **אחת** לכל דפי השיר הבודד. השיר נטען לפי `?slug=...` בכתובת |
| `songs-data.js` | **מקור האמת היחיד** לכל השירים. גם `songs.html` וגם `song.html` קוראים ממנו |
| `LOGO.png`, `victoria.jpeg` | תמונות האתר |
| `admin-local.py` | מריץ את דף הניהול מקומית וכותב ישירות לקבצים (`python admin-local.py`) |
| `admin/` | דף ניהול השירים. הכניסה בהזדהות GitHub, ולא מופיע בגוגל. ראו [SETUP-ADMIN.md](SETUP-ADMIN.md) |
| `worker/` | Cloudflare Worker שמבצע את ההזדהות מול GitHub ואת הפרסום בפועל |
| `reference/` | חומרי רקע מהעיצוב המקורי (לא חלק מהאתר החי) |

## איך מוסיפים שיר חדש

**הדרך הרגילה: דף הניהול.** ממלאים טופס בעברית, והשיר מתפרסם לאתר בלחיצה אחת. הדף תומך
בהוספה, עריכה, הסתרה, מחיקה ושינוי סדר, ובהעלאת קובץ MP3 ותמונה בגרירה.
הוראות למשתמש: [admin/HOWTO.md](admin/HOWTO.md).

### מקומית, מהמחשב

```
python admin-local.py
```

נפתח `http://localhost:8745/admin/`. כל שינוי נכתב ישירות לקבצים בתיקייה, ואז מתבצע
`git commit` ו-`git push` — כך שהאתר מתעדכן תוך כדקה. השרת מאזין רק למחשב המקומי.

לשמור בלי לדחוף ל-GitHub: `set PUSH=0 && python admin-local.py` (ב-Windows).

### מהאתר, בשביל משתמש נוסף

אותו דף בדיוק, מתארח ב-`rozenmusic.co.il/admin/`. הכניסה בהזדהות GitHub: מי שהוא
collaborator בריפו יכול לפרסם, והקומיטים נרשמים על שמו. דורש הקמה חד-פעמית —
ראו [SETUP-ADMIN.md](SETUP-ADMIN.md).

**עריכה ידנית** עדיין אפשרית. `songs-data.js` הוא מערך JSON בתוך `const SONGS = [...]`:

```js
{
  "slug": "shem-ktzar-ingili",      // מזהה ייחודי לכתובת ה-URL (אותיות לועזיות, מקפים)
  "title": "שם השיר",
  "performer": "שם המבצע/ת",         // ריק אם לא רלוונטי
  "tags": ["ז'אנר", "סוג אירוע"],
  "credits": "מילים, לחן, הפקה",
  "blurb": "משפט או שניים על השיר.",
  "lyricsExcerpt": "קטע מילים או המילים המלאות",
  "youtubeId": "XXXXXXXXXXX",       // ה-ID מכתובת היוטיוב, או null
  "audioSrc": null,                 // למשל "audio/shem.mp3", אם אין יוטיוב
  "coverImage": null,               // למשל "covers/shem.jpg", לשירים עם MP3
  "duration": null,
  "priceNote": "לפי פנייה",
  "thumbGradient": "from-primary/40 to-tertiary/40",  // צבעי הרקע כשאין תמונה
  "hidden": false                   // true = השיר נשמר אבל לא מוצג באתר
}
```

> **חשוב בעריכה ידנית:** הקובץ חייב להישאר JSON תקין — מרכאות כפולות, בלי הערות בתוך
> המערך, ובלי פסיק אחרי האיבר האחרון. אם שוברים את זה, דף הניהול לא יצליח לקרוא אותו.

- אם יש `youtubeId` — הדף יציג את הסרטון המוטמע, ותמונת התצוגה בקטלוג תישאב מיוטיוב.
- אם אין `youtubeId` אבל יש `audioSrc` — יוצג נגן שמע פשוט.
- אם אין אף אחד מהשניים — יוצג "קטע ההאזנה יעלה בקרוב".
- `hidden: true` מסתיר את השיר מהקטלוג ומחזיר "השיר לא נמצא" בדף הבודד.

**בדף הבית (`index.html`)** יש 3 כרטיסים סטטיים בקטע "שירים שפורסמו" (לא נטענים אוטומטית
מ-`songs-data.js`) — אם רוצים שהם ישקפו שירים חדשים, צריך לעדכן אותם ידנית שם
(חיפוש `Published Song Card`). דף הניהול לא נוגע בהם.

## הרצה מקומית לבדיקה

```
python -m http.server 8743
```
ואז פותחים `http://localhost:8743`.

## פריסה ל-GitHub Pages + דומיין אישי

1. יוצרים ריפוזיטורי חדש ב-GitHub ומעלים את כל הקבצים בתיקייה הזו (כולל `songs-data.js`, לא רק ה-HTML).
2. ב-Settings → Pages, בוחרים את הענף (למשל `main`) כמקור. GitHub ייתן כתובת כמו `username.github.io/repo-name`.
3. **לדומיין אישי**: אחרי הרכישה, ב-Settings → Pages → Custom domain מזינים את הדומיין. GitHub ייצור אוטומטית קובץ `CNAME` בריפו עם הדומיין. בנוסף צריך להגדיר אצל ספק הדומיין רשומת DNS (בדרך כלל `CNAME` ל-`username.github.io`, או רשומות `A` לכתובות של GitHub Pages — מופיע בדיוק בהוראות של GitHub).
4. מומלץ לסמן "Enforce HTTPS" ב-Settings → Pages אחרי שהדומיין מאומת.

## טופס יצירת קשר

הטופס ב-`index.html` **לא נשלח לשרת** — בלחיצה על "שליחה בוואטסאפ", קוד ה-JS (בתחתית `index.html`, ליד ההערה `Contact form -> WhatsApp`) בונה הודעה מנוסחת מהשדות (שם, טלפון, סוג פרויקט, הסיפור) ופותח קישור `wa.me` עם מספר הוואטסאפ של ויקטוריה, ובו ההודעה מוכנה מראש לשליחה.

כדי לעדכן את מספר הוואטסאפ שאליו מגיעות הפניות, יש לערוך את הקבוע `WHATSAPP_NUMBER` באותו קטע קוד.
